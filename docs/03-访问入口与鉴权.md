# 03 · 访问入口与鉴权

## 1. 统一入口（Nginx Proxy Manager）

所有服务收敛到 `http://192.168.1.88/`（当前网段下是 `http://<本机IP>/`，见文末"雷区"）。

| 子路径 | 上游 | 网关密码 | 改写 |
|---|---|---|---|
| `/` | homepage:3000 | 无 | 直接代理 |
| `/jellyfin` | jellyfin:8096 | 无 | `rewrite ^/jellyfin(/.*)$ $1 break` 剥前缀 |
| `/qbittorrent` | qbittorrent:8080 | 无 | 剥前缀 + 隐藏 `Referer/Origin/Authorization` |
| `/files` | alist:5244 | 无（AList 自带账号） | **不剥前缀**（AList 的 `site_url` 含 `/files`） |
| `/portainer` | portainer:9000 | ✅ `auth_basic` | 剥前缀 |
| `/code` | host.docker.internal:8081 | ✅ `auth_basic` | 剥前缀 + 重写 302 相对跳转 |

- 网关账号在 NPM 的访问列表 `internal`（`satisfy any`），用户名 `nxl`，密码见 `APIKey.txt`。
- 另有一个**内部**代理主机，域名 `npm` → `jellyfin:8096`，只给 Homepage 的 Jellyfin Widget 用（它硬编码 `/emby` 旧路径，这里用 rewrite 桥接）。

## 2. 各服务自己的认证

| 服务 | 认证方式 |
|---|---|
| Jellyfin | 账号密码；Homepage 用 API Key 取数 |
| qBittorrent | `admin` + WebUI 密码（已固定，见 APIKey.txt） |
| AList | 自带账号（guest / admin），与网关密码同值 |
| Portainer | 自己的 admin 账号（见 APIKey.txt） |
| code-server | `config.yaml` 里的密码 |
| NPM 管理台 | admin@example.com（见 APIKey.txt） |

## 3. 远程访问（EasyTier）

```
手机 EasyTier App ──(nxl-home, 密钥见 APIKey.txt)──► 10.144.144.x
                                                        │
                                        服务器虚拟 IP 10.144.144.1
                                                        │
                                          子网路由 192.168.1.0/24
                                                        ▼
                                              家里局域网 http://192.168.1.88
```

前提：服务器本身在 `192.168.1.0/24` 网段里。**当前在手机热点上，这条链路是断的。**

## 4. 雷区清单（换网段必看）

入口地址被硬编码在 4 个地方，必须**同时**改：

| 位置 | 字段 | 现在 |
|---|---|---|
| NPM 代理主机 1 | `server_name`（domain_names） | `192.168.1.88` |
| `homepage/config/services.yaml` | 每个卡片的 `href` | `http://192.168.1.88/...` |
| `alist/config.json` | `site_url` | `http://192.168.1.88/files` |
| EasyTier | `--proxy-networks` | `192.168.1.0/24` |

另外 `HOMEPAGE_ALLOWED_HOSTS` 必须包含"你用来访问的主机名:端口"，否则 Homepage 直接 400。

### 症状 → 原因

| 症状 | 原因 |
|---|---|
| `/` 能开，子路径全 404 | 访问用的 Host 不在 NPM 的 `server_name` 里 |
| 页面 400 Bad Request | `HOMEPAGE_ALLOWED_HOSTS` 没包含当前 Host |
| `/files` 401 或登录后又被弹回 | 网关 basic auth 覆盖了 AList 的 JWT（所以 `/files` 故意不加网关密码） |
| `/portainer`、`/code` 无限要密码 | 浏览器缓存了错误的 basic 凭据，清站点数据 |
| `/jellyfin` 404 | 少了 `rewrite` 剥前缀，或 Jellyfin 的 base URL 被设成了 `/jellyfin` |

## 5. 建议的目标形态

- 用域名 `nxl.lan` 代替 IP（路由器 DNS 一条记录 + NPM domain_names 多值）
- 容器端口全部只绑 `127.0.0.1`，NPM 是唯一对外面
- 密钥从 `services.yaml` 迁到 `{{HOMEPAGE_VAR_*}}` + `.env`(600)
