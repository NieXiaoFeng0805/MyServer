> 项目名 `docker`，编排文件 `/data/docker/docker-compose.yml`，网络 `docker_default`。

## 3. 依赖关系

- `homepage` 依赖 `docker.sock`（容器状态）、`jellyfin`（媒体统计）、`qbittorrent`（下载统计）、`portainer:9000`（容器计数）。任一挂掉只会让对应 Widget 显示错误，页面本身不受影响。
- `npm` 依赖所有上游容器名解析（`homepage` / `jellyfin` / `qbittorrent` / `alist` / `portainer`），以及 `host.docker.internal:8081` 指向 code-server。
- `alist` 只依赖自身配置与两个挂载目录。
- `jellyfin` 依赖 NVIDIA runtime（GPU 透传），驱动升级后需要重启容器。

## 5. 变更流程

1. 改 `/data/docker/docker-compose.yml`
2. `cd /data/docker && docker compose up -d <service>`（只重建受影响的服务）
3. `docker compose ps` 确认 healthy
4. 更新本仓库 `compose/docker-compose.yml` 与本文件的端口/端口表
