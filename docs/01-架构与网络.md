### 4.3 代理

`127.0.0.1:7897`（Clash Verge Rev，用户态进程，非 systemd）是长期基础设施：

- 只监听回环，外部控制器走 unix socket（旧的 0.0.0.0:9090 已不存在）
- ⚠️ **踩坑**：shell 里带 `HTTP(S)_PROXY` 时，连本地服务也会被劫持。跑本地请求前先
  `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy -u all_proxy <cmd>`

## 6. 已知架构问题

1. **入口单点**：NPM `server_name`、首页链接、AList `site_url` 全都写死 `192.168.1.88`，换网段即全断。
2. **单盘无冗余**：`/data` 一块消费级 HDD，无 RAID / 无备份 / 无 SMART 监控。
3. **桌面与服务器混跑**：Firefox + QQ + GNOME 常驻吃掉约 2–3G 内存。
4. **compose 与运行态会漂移**：改了 compose 没 `up -d`，容器还是旧配置（端口绑定/内存限制就是这样）。
