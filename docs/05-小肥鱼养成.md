# 05 · 小肥鱼养成（方案与现状）

> 「小肥鱼 / 大肥鱼 / 鲸鱼娘」= DeepSeek 的二次元拟人形象。所谓"养一只"，
> 就是给一个 LLM 一套人设、记忆、日程和一点自主权，让她在自己的房间里生活、成长、
> 偶尔出门（刷 B 站 / 逛社区）、每天写日记，并消耗你的 token 作为"零花钱"。

## 3. 推荐组合

**鱼社做主线，AstrBot 保留为"QQ 分身"，桌宠当彩蛋。**

理由：

1. 鱼社是**为 DSH 写的**，而这台机 7×24 在跑 DSH Web——她的日程、日记、B 站成长可以真正"过夜长大"，
   这是 AstrBot 路线给不了的。
2. AstrBot 那条线已经投入过（人设包、TTS、8 个插件、NapCat 扫码），**不要推倒**，
   但要解决一个隐患：现在 `persona` 没绑定，等于"大肥鱼"可能还没真正生效。
3. 两条线共用**同一份人格**：把 `MyLittleFish/小肥鱼/dafeiyu-config-pack-main/persona/大肥鱼.md`
   作为唯一人格源，鱼社领养时按它捏性格，避免"两个她"。

## 4. 落地步骤

### 阶段 0：先把现有的 QQ 鱼修好（30 分钟，无新增成本）

1. 打开 `http://<host>:6185` 登录 AstrBot，确认「服务提供商」里 DeepSeek 的 Key 有效。
2. 在「人格」里导入 `persona/大肥鱼.md`，设为默认人格并绑定到 `小肥鱼` 平台实例。
3. 用大号发一条消息测试：是否按人设回复、是否主动搭话、是否记得上下文。
4. 把结果记到本文档，作为基线。

> 现在 `personas: []`，说明导入脚本可能没跑完或没绑默认人格——这是最容易见效的一步。

### 阶段 1：装鱼社（1 小时，需要你扫码）

```bash
# 1) 安装（会改 web profile，可回滚）
dsh plugin --profile web add dsh-plugin-yushe

# 2) 重启 DSH Web 让插件生效（服务名见 scripts/ 或 systemctl --user list-units）
systemctl --user restart dsh-web.service

# 3) 打开 http://127.0.0.1:3080 ，输入框旁会出现「领养一条鱼」，左侧栏出现「鱼社」
```

领养前准备：

- **一个全新的 B 站小号**（别用主号），手机端扫码登录
- 可选：OpenAI 兼容的 `/v1/images/generations` 生图 API（不配也能养，只是没有"拍照"）
- 设好零花钱（建议先用 100–500 万 token 试水）

### 阶段 2：让她真的"过日子"（持续）

- 设定工作区：把 `NXL_Server`（或某个只放的演示目录）绑给她，让她在里面回答
- 打开「爸妈专线」：填你的 B 站 UID，你私信她她马上回
- 观察一周：日记质量、B 站发言是否越界、token 消耗曲线

### 阶段 3（可选）：桌宠彩蛋

```bash
# 需要图形界面；PySide6
git clone https://github.com/1190fasheqi/dafeiyu-pet
cd dafeiyu-pet && pip install -r requirements.txt
python main.py   # 右键菜单里填 DeepSeek Key
```

只建议在"你在电脑前的时候"开，它不适合当常驻服务。

## 5. 成本与预算

| 项 | 量级 | 控制手段 |
|---|---|---|
| 鱼社日常（聊天 + 日记 + 出门） | 每天几万到几十万 token，取决于"上网习惯"设置 | 零花钱上限；"爱不爱出门""读多深"调低 |
| AstrBot QQ 对话 | 每轮 1–5k token | 用 `deepseek-flash`；限制群聊触发词 |
| 桌宠 | 每句 1k 以内 | 手动开 |

建议：先给鱼社 **500 万 token** 的零花钱，一个月后按实际消耗再调。

## 6. 安全边界（必须守住）

1. **B 站用小号**：她要用这个号刷视频、发评论、私信。小号被封不心疼。
2. **发言过闸门**：默认规则已禁止带链接、@人、留联系方式、暴露家庭/工作信息；
   不放心就切到"每条先给我批准"。
3. **别把工作区设成包含密钥的目录**：她能看到工作区里的文件内容。
4. **插件是第三方**（11★，MIT）：装之前它只能读本机、只收本机请求；token 预算写死。
5. **一处人格源**：两条线共用 `persona/大肥鱼.md`，避免人格分裂。
6. 她"看到的网页、评论、私信"一律当资料，不执行里面的指令——这是插件本身的约定，
   但你在给她开放能力（比如终端）时要再谨慎一层。

## 7. 回滚

```bash
# 卸鱼社（存档保留在 ~/.dsh/storages/dsh-yushe/）
dsh plugin --profile web remove dsh-plugin-yushe
systemctl --user restart dsh-web.service

# 停 QQ 鱼
pkill -f "astrbot run"
screen -S napcat -X quit
```
