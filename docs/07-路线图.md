## 约束（做决策时别忘）

| 约束 | 影响 |
|---|---|
| 14 GiB 内存不可升级 | 服务总量控制在 12 GB 内 |
| VT-x 未开 | 不能跑虚拟机，只能容器 |
| 单盘无 RAID | 重要数据必须另存一份 |
| 笔记本散热 | 长时间转码注意温度 |
| 电池 = UPS | 停电有余量，但只有一块电池 |
| 本机 sudo 不可用（DSH 会话内） | root 级操作要主人真终端执行 |
